# Huwaidah Martina - Portfolio

Static website (HTML, CSS, vanilla JS). No build step.

## Before publishing
1. Add your photo: `assets/img/profile.jpg` (portrait, about 800x1000 px). Until then the site shows the "HM" initials.
2. Add your CV: `assets/Huwaidah_Martina_CV.pdf` (the Download CV buttons point to this file name).
3. Optional: link the 3 research cards in `projects.html` (see the comment inside the file).

## Deploy
GitHub repo -> Netlify (Import from Git, build command empty, publish directory `.`) -> custom domain.
